# Hood Yacht Club — Staking UI

Next.js front-end concept for Hood Yacht Club.

## Run

```bash
npm install
npm run dev
```

Create a standard Next.js app and replace the `app/` folder with the one here. Put `hood-yacht.gif` in `public/` (already included in this bundle).

The current page is a front-end demo. Connect your wallet provider, NFT staking contract, $YATCH token contract, reward calculation, and the canonical NVDA asset/pool you intend to support before production.
